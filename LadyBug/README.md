# 🐞 레이디버그 (Ladybug)

폰을 기울여 무당벌레를 움직이며 위에서 내려오는 세균을 피하고, 아이템으로 반격하는 모바일 아케이드 게임입니다.
옛 게임 '레이디버그'를 모바일용으로 다시 만든 프로젝트로, HTML 파일 하나로 동작합니다.

**▶ 플레이:** https://<내아이디>.github.io/ladybug/ladybug.html

> 폰 브라우저(크롬, 사파리)로 열어 주세요. 기울기 조작은 HTTPS 주소에서만 작동합니다.

---

## 조작

| 방식 | 설명 |
| --- | --- |
| 기울기 (기본) | 폰을 기울인 쪽으로 무당벌레가 걸어갑니다. 시작할 때 3초 동안 지금 든 자세를 기준으로 맞춥니다. |
| 터치 | 화면 아무 곳이나 끌면 그만큼 움직입니다. 센서를 쓸 수 없는 환경에서는 자동으로 터치로 바뀝니다. |
| 키보드 (PC) | 방향키 또는 WASD로 이동, `Esc`/`P`로 일시정지 |

- 아이폰은 '시작하기'를 누를 때 동작 센서 권한을 묻습니다. **허용**을 눌러 주세요.
- 메뉴에서 기울기 감도(낮게·보통·높게)를 고를 수 있고, 일시정지 메뉴에서 기울기 기준점을 다시 맞출 수 있습니다.
- 플레이 중에는 화면 회전 잠금을 켜 두는 것을 권장합니다.

## 아이템

아이템은 위에서 무작위로 떨어지며, 모두 닿은 세균을 없앱니다.

| 아이템 | 지속 | 효과 |
| --- | --- | --- |
| 이동형 꽃 | 3초 | 무당벌레와 합체해 빙글빙글 돌며 몸을 지킵니다. 그동안 무적입니다. |
| 정지형 꽃 | 5초 | 먹은 자리에 이동형 꽃보다 3배 큰 꽃이 피어 회전합니다. |
| 나뭇잎 | 2초 | 왼쪽 위·위·오른쪽 위로 3장이 날아가 화면 위쪽에서 회전하다 사라집니다. |
| 벌 | 화면 밖까지 | 먹은 자리에 무당벌레를 가릴 만큼 큰 벌이 나타나 천천히 위로 올라갑니다. |
| 콩벌레 | 6초 | 바라보던 방향으로 굴러가 화면 벽에 튕기며 돌아다닙니다. |

## 세균

| 세균 | 등장 | 특징 |
| --- | --- | --- |
| 보라 세균 | 레벨 1 | 기본형. 내려오면서 무당벌레 쪽으로 다가옵니다. |
| 막대균 | 레벨 2 | 빠르게 내리꽂힙니다. |
| 바이러스 | 레벨 3 | 느리지만 끈질기게 따라옵니다. |

레벨 2부터는 빈틈 하나만 남기고 한 줄로 몰려오는 무리도 나옵니다.

## 규칙과 점수

- 목숨 3개, 세균에 닿으면 1개를 잃고 1.6초 동안 무적이 됩니다.
- 15초마다 레벨이 올라 세균이 더 자주, 더 빠르게 나옵니다.
- 점수: 버틴 시간 1초당 10점, 세균 처치 20점(연속 처치 시 보너스), 아이템 획득 50점
- 최고 점수는 브라우저에 저장됩니다.

## 내 GitHub에 올리기 (GitHub Pages)

1. 새 저장소(예: `ladybug`)를 **Public**으로 만듭니다.
2. `ladybug.html`과 `README.md`를 업로드합니다.
3. **Settings → Pages**에서 Branch를 `main` / `(root)`로 고르고 저장합니다.
4. 1~2분 뒤 `https://<내아이디>.github.io/ladybug/ladybug.html`로 접속합니다.

`ladybug.html`을 `index.html`로 이름을 바꾸면 주소를 `https://<내아이디>.github.io/ladybug/`로 줄일 수 있습니다.

## 튜닝

게임 숫자는 `ladybug.html` 스크립트 맨 위의 `CONFIG`에 모여 있습니다.

```js
const CONFIG = {
  lives: 3,              // 목숨 수
  levelEvery: 15,        // 몇 초마다 레벨업
  spawn: { base: 0.62 }, // 세균 등장 간격(초)
  mflower: { duration: 3 },
  sflower: { duration: 5, scale: 3 },
  // ...
};
```

## 개발용 콘솔 명령

브라우저 개발자 도구 콘솔에서 쓸 수 있습니다.

```js
__ladybug.give('bee')   // 아이템 바로 사용: mflower, sflower, leaf, bee, pillbug
__ladybug.god()         // 무적 켜기 (끄기: __ladybug.god(false))
__ladybug.info          // 현재 점수, 레벨, 적 수 확인
```

## 기술 메모

- HTML5 Canvas 2D, 순수 JavaScript
- 기울기: `DeviceOrientationEvent` (iOS 13+는 `requestPermission` 필요, HTTPS 필수)
- 효과음: Web Audio API로 직접 합성
- 플레이 중 화면 꺼짐 방지: Screen Wake Lock API (지원하는 브라우저에서만)
